# 📇 Core Java Contact Management System

A console-based Contact Management System developed using Core Java. This project demonstrates CRUD operations, searching, sorting, and collection handling using `ArrayList` and `Collections.sort()`.

## 🚀 Features

- ➕ Add Contact
- 📋 View All Contacts
- 🔍 Search Contact by ID
- 👤 Search Contact by Name
- ✏️ Update Contact Details
- ❌ Delete Contact
- 📊 Count Total Contacts
- 🔤 Sort Contacts by Name
- 📧 Sort Contacts by Email
- 📱 Sort Contacts by Mobile Number

## 🛠 Technologies Used

- Java (Core Java)
- Eclipse IDE
- Collections Framework
- ArrayList
- Collections.sort()
- Lambda Expressions
- Object-Oriented Programming (OOP)
